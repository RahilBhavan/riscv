# Design and geometry sources

The palette and typography follow Rahil's user-authorized `rahil-design` skill. Anton and IBM Plex Sans are embedded from its font assets, with the accompanying SIL Open Font License files under `docs/textbook/fonts/`.

The isometric drawing uses a vendored copy of `iso-kit.mjs` and `iso.css` from Rahil's installed Anatomy skill (the skill’s `kit/` directory), whose skill metadata declares the MIT license. The conveyor composition, parts layout, educational state model and other instructional SVGs were authored for this project. No source image or personal photograph is used.

The review presentation is delivered as self-contained editable HTML and a rendered PDF. No PowerPoint runtime was available in this environment, so no PPTX export is claimed. The book and deck use native text, HTML tables and inline SVG, rather than flattened page images.
